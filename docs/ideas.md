# Ideas parking lot

Not in scope. Suggestions to consider after the prototype passes its checks (see `design.md`).

- **Solo and mute per layer in the tuning panel.** Would make mixing sessions faster for Nico. Dev-only tool, not a game feature.
- **Level meters per channel in the tuning panel.** Shows when an enemy effect is pushing a layer too hard.
- **Kick tuning follows the chord** (A on Am7, F on Fmaj7). Some house tracks do this; could make the low end tighter with the bass. Needs an ear test.
- **Sidechain pumping as a core upgrade.** The core's kick ducks the chords and pads, adding groove. Could be one of the session 5 core perks.
